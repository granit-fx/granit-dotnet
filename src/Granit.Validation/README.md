# Granit.Validation

FluentValidation module for Granit. Provides `GranitValidator<T>`, standardized error codes, and validation extensions for regulated identifiers (Belgian NISS, French RPPS/ADELI/FINESS, IBAN, E.164).

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Validation
```

## Dependencies

- `Granit.Http.ExceptionHandling`
- `Granit.Localization`
