# Granit.Timeline.AI

AI-powered timeline summarization and anomaly detection for Granit.Timeline. Uses LLM-based analysis to summarize activity streams and detect unusual patterns (bulk edits, off-hours activity, privilege escalation).

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Timeline.AI
```

## Dependencies

- `Granit.AI`
- `Granit.Timeline`
