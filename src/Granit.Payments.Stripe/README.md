# Granit.Payments.Stripe

Stripe payment provider for Granit.Payments. Implements IPaymentProvider, ICheckoutSessionFactory, IPaymentMethodManager, and IPaymentWebhookVerifier.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Payments.Stripe
```

## Dependencies

- `Granit.Payments`
- `Stripe.net`
