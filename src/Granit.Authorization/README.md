# Granit.Authorization

RBAC permission system for Granit applications. Provides permission definitions, ASP.NET Core integration, and caching-aware permission checks.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Authorization
```

## Dependencies

- `Granit.Caching`
- `Granit.Users`
