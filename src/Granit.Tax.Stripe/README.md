# Granit.Tax.Stripe

Stripe Tax API integration for Granit. Best for B2C global SaaS needing
multi-jurisdiction tax calculation (US Sales Tax, EU VAT, UK VAT).

## Configuration

```json
{
  "Tax": {
    "Stripe": {
      "SecretKey": "sk_test_xxx",
      "ProductTaxCode": "txcd_10000000"
    }
  }
}
```
