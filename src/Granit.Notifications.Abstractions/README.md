# Granit.Notifications.Abstractions

Inter-module contracts for Granit.Notifications: `INotificationPublisher`,
`INotificationChannel`, `NotificationType<T>`, domain entities, and delivery context.
Reference this package instead of `Granit.Notifications` when you only need notification
contracts without the engine implementation.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Notifications.Abstractions
```

## Dependencies

- `Granit`
- `Granit.QueryEngine.Abstractions`
