# Granit.Payments.Mollie

Mollie payment provider for Granit.Payments (EU-sovereign PSP, NL-based). Implements IPaymentProvider, ICheckoutSessionFactory, IPaymentMethodManager, and IPaymentWebhookVerifier.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Payments.Mollie
```

## Dependencies

- `Granit.Payments`
- `Mollie.Api`
