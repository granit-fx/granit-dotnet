# Granit.Invoicing.EntityFrameworkCore

EF Core persistence for Granit.Invoicing. InvoicingDbContext, EfInvoiceStore, EfCreditNoteStore, entity configurations, and gap-free invoice number generator.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Invoicing.EntityFrameworkCore
```

## Dependencies

- `Granit.Invoicing`
- `Granit.Guids`
- `Granit.Persistence.EntityFrameworkCore`
