# Granit.AI.Anthropic

Anthropic (Claude) provider for Granit.AI. Chat completion via Claude Opus, Sonnet, and Haiku models.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.AI.Anthropic
```

## Dependencies

- `Granit.AI`
