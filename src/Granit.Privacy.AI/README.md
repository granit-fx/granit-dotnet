# Granit.Privacy.AI

AI-powered PII detection for Granit.Privacy. Scans text for personally identifiable information using LLM for GDPR compliance.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Privacy.AI
```

## Dependencies

- `Granit.AI`
- `Granit.Privacy`
