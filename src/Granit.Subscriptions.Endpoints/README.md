# Granit.Subscriptions.Endpoints

Minimal API endpoints for Granit.Subscriptions. Plan admin CRUD, subscription management, seat assignment, and QueryEngine pagination with RBAC permissions.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Subscriptions.Endpoints
```

## Dependencies

- `Granit.Authorization`
- `Granit.Subscriptions`
- `Granit.QueryEngine.AspNetCore`
- `Granit.Validation`
