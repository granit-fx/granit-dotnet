# Granit.Documents.Notifications

Notification bridge for the Granit.Documents module (F10). Publishes emails on
share grant / revoke and quota threshold events through `Granit.Notifications`.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Documents.Notifications
```

## Notification types

| Name | Trigger | Default channel | Severity |
| --- | --- | --- | --- |
| `documents.shared` | `DocumentShareGrantedEvent` (User grantee) | Email | Info |
| `documents.share_revoked` | `DocumentShareRevokedEvent` (User grantee) | Email | Info |
| `documents.quota_warning` | host-published when usage crosses early-warning threshold | Email | Warning |
| `documents.quota_exceeded` | host-published when an upload is rejected for quota | Email | Error |

Templates ship as embedded HTML in EN + FR (the framework baseline). Other
cultures should be generated by `scripts/translate-templates.py` with the
`<!-- AUTO-TRANSLATED -->` marker.
