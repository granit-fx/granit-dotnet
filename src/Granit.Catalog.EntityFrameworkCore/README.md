# Granit.Catalog.EntityFrameworkCore

EF Core persistence layer for `Granit.Catalog`. Provides `CatalogDbContext`, `EfProductReader`, `EfProductWriter`, and entity configurations. Compatible with SQL Server and PostgreSQL.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Catalog.EntityFrameworkCore
```

## Dependencies

- `Granit.Catalog`
- `Granit.Guids`
- `Granit.Persistence.EntityFrameworkCore`
