# Granit.Authentication.OpenIddict

OpenIddict token validation for Granit resource servers. Validates JWT/reference tokens
from a remote Granit OpenIddict server without embedding the full OIDC stack.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Authentication.OpenIddict
```

## Dependencies

- `Granit.Users`
