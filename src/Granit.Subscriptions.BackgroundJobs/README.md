# Granit.Subscriptions.BackgroundJobs

Background jobs for Granit.Subscriptions. Trial expiration scan, billing period end detection, and cancel-at-period-end processing.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Subscriptions.BackgroundJobs
```

## Dependencies

- `Granit.BackgroundJobs`
- `Granit.Subscriptions`
