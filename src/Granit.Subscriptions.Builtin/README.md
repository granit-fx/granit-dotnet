# Granit.Subscriptions.Internal

Self-hosted subscription provider for Granit. Zero external dependency — all subscription lifecycle management is handled locally by Granit.Workflow, BackgroundJobs, and Billing module events.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Subscriptions.Internal
```

## Dependencies

- `Granit.Subscriptions`
