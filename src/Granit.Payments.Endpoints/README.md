# Granit.Payments.Endpoints

Minimal API endpoints for Granit.Payments. Charge, refund, checkout, payment methods, and webhook endpoints with RBAC, idempotency, and provider-specific signature verification.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Payments.Endpoints
```

## Dependencies

- `Granit.Authorization`
- `Granit.Http.Idempotency`
- `Granit.Payments`
- `Granit.Validation`
