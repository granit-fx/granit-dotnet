# Granit.Features.EntityFrameworkCore

EF Core persistence for Granit.Features. Provides TenantFeatureOverride entity, FeaturesDbContext, and EfCoreFeatureStore with ISO 27001 audit trail.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Features.EntityFrameworkCore
```

## Dependencies

- `Granit.Features`
- `Granit.Persistence`
