# Granit.Invoicing.BackgroundJobs

Background jobs for Granit.Invoicing. Overdue invoice detection and external sync polling.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Invoicing.BackgroundJobs
```

## Dependencies

- `Granit.BackgroundJobs`
- `Granit.Invoicing`
