# Granit.Bff.EntityFrameworkCore

EF Core persistence layer for BFF session tokens. Alternative to the default
`IDistributedCache`-backed store for deployments without Redis.

## Features

- `BffDbContext` — isolated DbContext with `BffSession` entity
- `EfCoreBffTokenStore` — `IBffTokenStore` implementation backed by EF Core
- Expired session cleanup handler
- Queryable sessions (list by user, revoke by user)

## Usage

Two mandatory steps:

```csharp
// 1. Declare the module dependency on your host module:
[DependsOn(typeof(GranitBffEntityFrameworkCoreModule))]
public sealed class YourHostModule : GranitModule
{
    public override void ConfigureServices(ServiceConfigurationContext context)
    {
        // 2. Register the isolated BffDbContext. The module registers
        //    IBffTokenStore; this call wires the DbContext it depends on —
        //    without it, IBffTokenStore fails to resolve at runtime.
        context.Builder.AddGranitBffEntityFrameworkCore(options =>
            options.UseNpgsql(connectionString));
    }
}
```

The extension targets `IHostApplicationBuilder` (use `context.Builder`). EF Core
migrations for `BffDbContext` must be generated by the consumer
(`dotnet ef migrations add ...`) — they are not created automatically.
