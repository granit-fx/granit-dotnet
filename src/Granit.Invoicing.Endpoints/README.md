# Granit.Invoicing.Endpoints

Minimal API endpoints for Granit.Invoicing. Invoice CRUD, PDF download, credit note management, RBAC permissions, and QueryEngine pagination.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Invoicing.Endpoints
```

## Dependencies

- `Granit.Authorization`
- `Granit.Invoicing`
- `Granit.QueryEngine.AspNetCore`
- `Granit.Validation`
