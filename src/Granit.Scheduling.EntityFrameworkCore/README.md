# Granit.Scheduling.EntityFrameworkCore

EF Core persistence layer for Granit.Scheduling. Provides SchedulingDbContext, EfScheduledActionStore, and entity configurations for the ScheduledAction aggregate. Compatible with SQL Server and PostgreSQL.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Scheduling.EntityFrameworkCore
```

## Dependencies

- `Granit.Scheduling`
- `Granit.Guids`
- `Granit.Persistence.EntityFrameworkCore`
