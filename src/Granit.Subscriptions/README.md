# Granit.Subscriptions

Subscription management for Granit. Plan catalog with lifecycle (Draft/Published/Archived), subscription FSM via Granit.Workflow (Trial/Active/PastDue/Suspended/Cancelled/Expired), per-seat pricing, scheduled plan changes via Granit.Scheduling, and provider pattern (Internal/Stripe).

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Subscriptions
```

## Dependencies

- `Granit`
- `Granit.Guids`
- `Granit.Scheduling`
- `Granit.Timing`
- `Granit.Workflow`
