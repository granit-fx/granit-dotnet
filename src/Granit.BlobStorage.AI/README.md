# Granit.BlobStorage.AI

AI-powered blob validator and classifier for Granit.BlobStorage. Uses LLM-based analysis to classify uploaded files (invoice, identity document, photo, contract, etc.) and detect PII in filenames before storage.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.BlobStorage.AI
```

## Dependencies

- `Granit.AI`
- `Granit.BlobStorage`
