# Granit.Mcp

MCP (Model Context Protocol) module for Granit. Auto-discovers tools, resources, and prompts from module assemblies, with output sanitization for GDPR compliance and OpenTelemetry diagnostics. Built on the official MCP C# SDK.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Mcp
```

## Dependencies

- `Granit`
- `ModelContextProtocol`
