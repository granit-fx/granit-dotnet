# Granit.Encryption

String encryption/decryption with AES-256-CBC and Vault Transit providers for Granit applications.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Encryption
```

## Dependencies

- `Granit`
