# Granit.Payments.EntityFrameworkCore

EF Core persistence for Granit.Payments. PaymentsDbContext, EfPaymentTransactionStore, EfPaymentMethodStore, webhook dedup store, entity configurations.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Payments.EntityFrameworkCore
```

## Dependencies

- `Granit.Payments`
- `Granit.Guids`
- `Granit.Persistence.EntityFrameworkCore`
