# Granit.Privacy.Regulations.Cookies

Bridge between `Granit.Privacy.Regulations` and `Granit.Http.Cookies`. Provides
regulation-aware cookie consent model resolution — maps `PrivacyRegulationProfile`
to `CookieConsentMode` for GPC signal enforcement and opt-in/opt-out cookie handling.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Privacy.Regulations.Cookies
```

## Dependencies

- `Granit.Http.Cookies`
- `Granit.Privacy.Regulations`
