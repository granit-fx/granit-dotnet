# Granit.Observability

Serilog and OpenTelemetry (OTLP to Loki/Tempo/Mimir) for Granit applications.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Observability
```

- `Granit`
