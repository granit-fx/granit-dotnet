# Granit.Templating.AI

AI-powered template assistance for Granit.Templating. Generate Scriban template drafts from natural language descriptions and enrich template data with AI.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Templating.AI
```

## Dependencies

- `Granit.AI`
- `Granit.Templating`
