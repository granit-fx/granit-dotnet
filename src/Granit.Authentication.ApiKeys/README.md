# Granit.Authentication.ApiKeys

Machine-to-machine (M2M) authentication via API keys for .NET applications.
Provides `ApiKeyAuthenticationHandler`, `IApiKeyStore`, `IApiKeyGenerator`,
and CIDR-based IP whitelisting.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Authentication.ApiKeys
```

## Dependencies

- `Granit.Http.ExceptionHandling`
- `Granit.Guids`
- `Granit.QueryEngine`
- `Granit.Users`
- `Granit.Timing`
