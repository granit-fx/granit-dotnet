# Granit.Payments

Provider-agnostic payment processing for Granit. PaymentTransaction aggregate with 6-state FSM, multi-provider resolution per tenant and payment method type, refunds, disputes, inbound webhook verification, and idempotent charge operations.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Payments
```

## Dependencies

- `Granit`
- `Granit.Guids`
- `Granit.Timing`
