# Granit.Validation.Endpoints

Minimal API endpoints for single-field and batch server-side validation using registered `IServerValidator` instances. Enables real-time (debounced) field validation without submitting the entire form.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Validation.Endpoints
```

## Dependencies

- `Granit.Http.ApiDocumentation`
- `Granit.Validation`
