# Granit.Subscriptions.Wolverine

Wolverine integration for Granit.Subscriptions. Handles provider sync after FSM transitions and processes inbound external events (webhooks).

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Subscriptions.Wolverine
```

## Dependencies

- `Granit.Subscriptions`
- `Granit.Wolverine`
