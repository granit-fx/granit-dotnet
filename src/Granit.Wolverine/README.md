# Granit.Wolverine

WolverineFx integration for Granit. Transactional outbox, ISO 27001 context propagation, and distributed tracing.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Wolverine
```

## Dependencies

- `Granit.Users`
- `Granit.Validation`
