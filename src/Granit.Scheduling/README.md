# Granit.Scheduling

Generic one-shot scheduled actions for Granit. Schedule typed payloads for future execution with cancellation, rescheduling, and audit trail. Complements `Granit.BackgroundJobs` (recurring cron) with date-specific one-shot actions.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Scheduling
```

## Dependencies

- `Granit`
- `Granit.Guids`
- `Granit.Timing`
