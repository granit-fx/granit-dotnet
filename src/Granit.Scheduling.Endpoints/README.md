# Granit.Scheduling.Endpoints

Minimal API endpoints for administering Granit scheduled actions. Exposes GET/DELETE/PUT routes for listing, cancelling, and rescheduling one-shot scheduled actions.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Scheduling.Endpoints
```

## Dependencies

- `Granit.Authorization`
- `Granit.Scheduling`
- `Granit.QueryEngine.Abstractions`
- `Granit.Validation`
