# Granit.Subscriptions.Features

Bridge between Granit.Subscriptions and Granit.Features. Implements IPlanIdProvider and IPlanFeatureStore to enable automatic feature flag cascade from subscription plans (Tenant Override → Plan → Default).

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Subscriptions.Features
```

## Dependencies

- `Granit.Subscriptions`
- `Granit.Features`
