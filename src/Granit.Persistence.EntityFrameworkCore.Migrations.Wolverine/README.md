# Granit.Persistence.Migrations.Wolverine

Wolverine integration for Granit.Persistence.Migrations. Dispatches migration batches
via `IMessageBus` (durable Outbox) with cascading handler support.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Persistence.Migrations.Wolverine
```

## Dependencies

- `Granit.Persistence.Migrations`
- `Granit.Wolverine`
