# Granit.AI.Mcp

Bridges MCP tools into Granit AI workspaces. IMcpToolSourceProvider injects external MCP tools as AITool in IChatClient pipelines, with a SamplingGuard for cost-controlled, rate-limited MCP sampling.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.AI.Mcp
```

## Dependencies

- `Granit.AI`
- `Granit.Mcp.Client`
