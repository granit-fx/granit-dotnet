# Granit.Invoicing.Wolverine

Wolverine integration for Granit.Invoicing. Handles subscription events (billing cycle, cancellation) to create invoices, and payment events to update invoice status.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Invoicing.Wolverine
```

## Dependencies

- `Granit.Invoicing`
- `Granit.Subscriptions` (for event types)
- `Granit.Wolverine`
