# Granit.Identity.Federated.GoogleCloud

Google Cloud Identity Platform (Firebase Auth) provider for `Granit.Identity`. Registered as Keyed Service with key `"GoogleCloud"` for multi-provider resolution.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Identity.Federated.GoogleCloud
```

## Dependencies

- `Granit.Identity.Federated`
