# Granit.Settings

Dynamic settings system with cascading resolution (User → Tenant → Global → Configuration → Default) for Granit applications.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Settings
```

## Dependencies

- `Granit.Caching`
- `Granit.Encryption`
- `Granit.Users`
