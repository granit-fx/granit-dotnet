# Granit.BlobStorage.Wolverine

Wolverine integration for Granit.BlobStorage. Recurring hourly job for automatic orphan blob cleanup — cleans up blobs stuck in Pending/Uploading for over 24 hours.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.BlobStorage.Wolverine
```

## Dependencies

- `Granit.BlobStorage`
- `Granit.BackgroundJobs`
- `Granit.Wolverine`
