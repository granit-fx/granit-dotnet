# Granit.Subscriptions.EntityFrameworkCore

EF Core persistence layer for Granit.Subscriptions. Provides SubscriptionsDbContext, EfPlanStore, EfSubscriptionStore, and entity configurations for plans, subscriptions, seats, and external mappings.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Subscriptions.EntityFrameworkCore
```

## Dependencies

- `Granit.Subscriptions`
- `Granit.Guids`
- `Granit.Persistence.EntityFrameworkCore`
