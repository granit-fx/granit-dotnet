# Granit.Payments.Wolverine

Wolverine integration for Granit.Payments. Handles InvoiceFinalizedEto, payment commands, and webhook processing.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Payments.Wolverine
```

## Dependencies

- `Granit.Payments`
- `Granit.Invoicing` (for event types)
- `Granit.Wolverine`
