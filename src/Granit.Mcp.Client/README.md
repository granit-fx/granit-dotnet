# Granit.Mcp.Client

MCP client module for Granit. Named factory (IMcpClientFactory) for connecting to external MCP servers via HTTP or stdio transport, with automatic credential forwarding.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Mcp.Client
```

## Dependencies

- `Granit.Mcp`
- `ModelContextProtocol`
