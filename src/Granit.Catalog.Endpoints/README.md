# Granit.Catalog.Endpoints

Minimal API endpoints for `Granit.Catalog`. Product CRUD, lifecycle (publish/archive), external mapping management, and QueryEngine pagination with RBAC permissions.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Catalog.Endpoints
```

## Dependencies

- `Granit.Authorization`
- `Granit.Catalog`
- `Granit.Http.Abstractions`
- `Granit.QueryEngine.AspNetCore`
- `Granit.Validation`
