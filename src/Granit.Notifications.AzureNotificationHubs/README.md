# Granit.Notifications.AzureNotificationHubs

Azure Notification Hubs provider for `Granit.Notifications.MobilePush`. Registered as Keyed Service with key `"AzureNotificationHubs"` for multi-provider resolution. Supports multi-platform push (iOS, Android, Windows) via FCM v1 payloads.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Notifications.AzureNotificationHubs
```

## Dependencies

- `Granit.Notifications.MobilePush`
