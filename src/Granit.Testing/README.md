# Granit.Testing

Shared test infrastructure for Granit modules. Eliminates boilerplate across 134+ test projects with `GranitTestFixture<TModule>`, AsyncLocal-backed fakes, and Bogus generators for domain types.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.Testing
```

## Dependencies

- `Granit.Core`
- `Granit.Security`
- `Granit.Timing`
- `Granit.Guids`
- `Bogus`
