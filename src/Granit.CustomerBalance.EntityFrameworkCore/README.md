# Granit.CustomerBalance.EntityFrameworkCore

EF Core persistence for Granit.CustomerBalance. CustomerBalanceDbContext, EfBalanceAccountStore, entity configurations.

Part of the [granit](https://granit-fx.dev) framework.

## Installation

```bash
dotnet add package Granit.CustomerBalance.EntityFrameworkCore
```

## Dependencies

- `Granit.CustomerBalance`
- `Granit.Guids`
- `Granit.Persistence.EntityFrameworkCore`
