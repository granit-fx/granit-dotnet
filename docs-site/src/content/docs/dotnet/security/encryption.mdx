Granit.Vault.Encryption provides AES-256-GCM field-level encryption for sensitive
entity properties. Encryption keys are sourced from Granit.Vault (HashiCorp Vault,
AWS KMS, Azure Key Vault) and versioned for seamless rotation. GDPR crypto-shredding
deletes the encryption key to make data irreversibly unreadable without touching the
encrypted ciphertext.
